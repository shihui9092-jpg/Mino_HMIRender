# MinoCameraController 镜头快速切换飘移问题修复说明

## 问题描述

当快速连续切换相机机位时(如快速按下 1→2→3),相机会带着车模飘出 Game 视口外,无法正常显示。

## 根本原因

相机 Transform 存在两个控制源同时作用,产生冲突:

1. **DOTween 系统**: 直接插值 `transform.position` 到目标位置
2. **轨道系统**: 在 `LateUpdate` 中通过 `ApplyOrbitTransform()` 根据轨道参数(yaw/pitch/distance/height/offset)计算位置

在机位过渡期间,两个系统同时作用导致:
- Position Tween 试图将相机移动到 A 点
- 轨道系统根据正在过渡的角度参数计算出 B 点
- 快速切换时使用 `Kill()` 中断动画,导致相机停在中间状态
- 累积偏移最终导致相机飘出视口

## 修复方案

采用"方案 A + 方案 C"的组合修复:

### 1. 移除 transform.position 直接 Tween(方案 A)
- 删除 `ApplyCameraPreset` 中对 `transform.position` 的直接插值
- 仅 Tween 轨道参数(yaw/pitch/height/offset/distance)
- 让 `ApplyOrbitTransform()` 统一根据轨道参数计算位置
- **优势**: 单一位置计算源,消除冲突

### 2. 使用 Complete() 替代 Kill()(方案 C)
- 切换机位时调用 `activePresetTween.Complete(withCallbacks: true)`
- 确保前一个机位的参数完整应用到目标值
- **优势**: 避免中间状态残留,减少累积误差
- **权衡**: 快速切换时会有轻微"跳帧"感

### 3. 添加 100ms 切换冷却时间
- 在 `HandlePresetHotkeys` 中限制最快切换频率为 10 次/秒
- **优势**: 防止过快操作导致的异常,给动画系统足够的响应时间

### 4. 标记 worldPosition 为 HideInInspector
- 保留字段但不再使用,确保旧配置导入时不报错
- **优势**: 向后兼容,不影响现有项目

### 5. 添加调试日志
- 输出每次切换的目标参数(yaw/pitch/distance)和过渡时长
- **优势**: 方便排查问题,追踪机位切换行为

#### 修改 4: HandlePresetHotkeys 方法(约第 707 行)
```csharp
private void HandlePresetHotkeys()
{
    if (cameraPresetSlots == null || IsShiftHeld())
    {
        return;
    }

    // 防止过快切换导致飘移,添加 100ms 冷却时间
    if (Time.unscaledTime - lastPresetSwitchTime < PresetSwitchCooldown)
    {
        return;
    }

    for (int i = 0; i < cameraPresetSlots.Count; i++)
    {
        MinoCameraPresetSlot slot = cameraPresetSlots[i];
        if (slot == null || slot.activationKey == KeyCode.None)
        {
            continue;
        }

        if (Input.GetKeyDown(slot.activationKey))
        {
            if (slot.view != null)
            {
                ApplyPresetByIndex(i);
                lastPresetSwitchTime = Time.unscaledTime; // 记录切换时间
            }
            break;
        }
    }
}
```

#### 修改 5: ApplyCameraPreset 方法(约第 1042 行)
```csharp
private void ApplyCameraPreset(MinoCameraPreset preset)
{
    if (preset == null)
    {
        return;
    }

    // 使用 Complete() 而非 Kill(),确保前一个机位参数完整应用,避免中间状态残留
    if (activePresetTween != null && activePresetTween.IsActive())
    {
        activePresetTween.Complete(withCallbacks: true);
    }

    Vector3 angles = preset.eulerAngles;
    float transitionDuration = Mathf.Max(0.05f, presetTransitionDuration);
    float shortestYawTarget = orbitYaw + Mathf.DeltaAngle(orbitYaw, angles.y);
    float shortestPitchTarget = orbitPitch + Mathf.DeltaAngle(orbitPitch, angles.x);
    isPresetTransitioning = true;

    Debug.Log($"[MinoCameraController] 切换机位: yaw={shortestYawTarget:F1}°, pitch={shortestPitchTarget:F1}°, distance={preset.orbitDistance:F2}, duration={transitionDuration:F2}s", this);

    activePresetTween = DOTween.Sequence();
    // 移除直接 Tween transform.position,避免与 ApplyOrbitTransform() 的轨道计算冲突
    // 仅 Tween 轨道参数,让 ApplyOrbitTransform() 统一计算位置
    activePresetTween.Join(DOTween.To(() => orbitYaw, value => orbitYaw = value, shortestYawTarget, transitionDuration));
    activePresetTween.Join(DOTween.To(() => orbitPitch, value => orbitPitch = value, shortestPitchTarget, transitionDuration));
    activePresetTween.Join(DOTween.To(() => orbitHeight, value => orbitHeight = value, preset.orbitHeight, transitionDuration));
    activePresetTween.Join(DOTween.To(() => orbitOffset, value => orbitOffset = value, preset.orbitOffset, transitionDuration));
    activePresetTween.Join(DOTween.To(() => orbitDistance, value => orbitDistance = value, preset.orbitDistance, transitionDuration));
    activePresetTween.OnKill(() => { isPresetTransitioning = false; });
    activePresetTween.OnComplete(() => { isPresetTransitioning = false; });
}
```

## 影响评估

### 对现有功能的影响

1. **机位切换**: ✓ 修复飘移问题,行为更稳定
2. **机位保存**: ✓ 仍然正常工作,但仅保存轨道参数
3. **参数导入导出**: ✓ 向后兼容,旧配置可正常导入
4. **自动回机位**: ✓ 不受影响
5. **拖拽旋转**: ✓ 不受影响

### 行为变化

1. **快速切换时的视觉效果**: 由于使用 `Complete()`,前一个动画会立即跳到终点,可能有轻微"跳帧"感
2. **切换频率限制**: 最快 10 次/秒(100ms 冷却),正常使用下不影响体验
3. **机位保存**: 不再保存 `worldPosition`,完全依赖轨道参数计算

### 兼容性

- ✓ 旧机位配置可正常加载(worldPosition 被忽略)
- ✓ 旧配置中的轨道参数仍然有效
- ⚠️ 如果旧机位的 worldPosition 与轨道参数不一致,可能需要重新调整保存

## 测试建议

请按照 `测试验证清单.md` 中的步骤进行验证,重点测试:

1. 单次切换是否平滑
2. 快速连续切换(1→2→3→4)是否准确停在最后一个机位
3. 中断切换是否正确处理
4. 疯狂按键是否稳定
5. 切换后的参数是否与预设一致

## 已知限制

1. 快速切换时会有"跳帧"感(使用 Complete() 的权衡)
2. 切换频率限制为 10 次/秒(100ms 冷却)
3. worldPosition 不再使用,旧机位可能需要重新调整
