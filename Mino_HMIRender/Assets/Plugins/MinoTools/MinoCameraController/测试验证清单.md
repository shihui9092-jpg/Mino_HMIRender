# MinoCameraController 镜头切换修复 - 测试验证清单

## 修复内容总结

本次修复解决了镜头快速切换时车模飘出视口的问题,主要修改包括:

1. **移除 transform.position 直接 Tween** - 避免与轨道系统的位置计算冲突
2. **使用 Complete() 替代 Kill()** - 确保前一个机位参数完整应用
3. **标记 worldPosition 为 HideInInspector** - 保持向后兼容性
4. **添加 100ms 切换冷却时间** - 防止过快连续切换
5. **添加调试日志** - 方便追踪机位切换参数

## 测试步骤

### 1. 单次切换测试
**目的**: 验证基本切换功能是否正常

**步骤**:
1. 进入 Play 模式
2. 按下机位 1 的快捷键(如数字键 1)
3. 等待过渡动画完成
4. 按下机位 2 的快捷键(如数字键 2)
5. 观察相机是否平滑过渡到机位 2

**预期结果**:
- ✓ 相机平滑过渡到目标机位
- ✓ 车模始终在视口内
- ✓ 过渡结束后相机位置稳定
- ✓ Console 输出切换日志显示正确的 yaw/pitch/distance 参数

1. 进入 Play 模式

3. 等待所有过渡动画完成
4. 观察最终停在机位 4 的位置

**预期结果**:
- ✓ 中间切换时有"跳帧"感(由于 Complete() 立即完成前一个动画)
- ✓ 最终准确停在机位 4 的预设位置
- ✓ 车模始终在视口内,无飘移
- ✓ Console 输出 4 条切换日志

4. 再次在过渡中途按下机位 1 的快捷键
5. 让最后一次切换完成

**预期结果**:
- ✓ 每次切换都会立即完成前一个动画
- ✓ 最终相机准确停在机位 1 的预设位置
- ✓ 无累积偏移或抖动

**步骤**:
1. 进入 Play 模式
2. 疯狂连续按键盘 1、2、3、4 键,持续 5-10 秒

**预期结果**:

### 5. 参数验证测试
**目的**: 验证切换后的轨道参数是否与预设一致

**步骤**:
1. 在 Scene 视图中记录机位 1 的预设参数:
   - eulerAngles (yaw, pitch)
   - orbitHeight
   - orbitOffset
   - orbitDistance
2. 进入 Play 模式
3. 执行快速连续切换测试(1→2→3→1)
4. 在 Inspector 中通过反射或 Debug 脚本读取当前运行时参数
5. 对比参数是否与预设一致

**预期结果**:
- ✓ orbitYaw 与预设 eulerAngles.y 一致(误差 < 0.1°)
- ✓ orbitPitch 与预设 eulerAngles.x 一致(误差 < 0.1°)
- ✓ orbitDistance 与预设一致(误差 < 0.01)
- ✓ orbitHeight 与预设一致(误差 < 0.01)
- ✓ orbitOffset 与预设一致(误差 < 0.01)

**验证方法**:
可以临时在 `ApplyCameraPreset` 的 `OnComplete` 回调中添加日志:
```csharp
activePresetTween.OnComplete(() => 
{ 
    isPresetTransitioning = false;
    Debug.Log($"[验证] 切换完成 - 当前参数: yaw={orbitYaw:F2}°, pitch={orbitPitch:F2}°, distance={orbitDistance:F3}, height={orbitHeight:F3}, offset={orbitOffset:F3}", this);
});
```

## 已知限制

1. **快速切换时的"跳帧"感**: 由于使用 `Complete()` 替代 `Kill()`,快速切换时前一个动画会立即跳到终点,可能产生视觉上的跳跃。这是为了避免飘移而做的权衡。

2. **100ms 冷却限制**: 最快切换频率为 10 次/秒,正常使用足够,但极端操作下可能忽略部分按键输入。

3. **worldPosition 不再使用**: 旧配置中的 worldPosition 数据将被忽略,完全依赖轨道参数计算位置。如果旧机位的 worldPosition 与轨道参数不一致,切换后可能与预期略有偏差,需要重新调整保存。

## 问题排查

如果测试中发现问题,请检查:

1. **飘移仍然存在**: 
   - 检查是否有其他脚本修改相机 Transform
   - 确认 orbitFocus 是否稳定(是否绑定到移动的对象)
   - 查看 Console 日志中的目标参数是否合理

2. **切换无响应**:
   - 检查 presetTransitionDuration 是否过大
   - 确认机位槽位是否正确配置
   - 查看是否触发了冷却时间(Console 无日志输出)

3. **位置偏差**:
   - 对比预设参数与运行时参数(使用参数验证测试)
   - 检查 orbitFocus 的位置是否正确
   - 确认 orbitHeight/orbitOffset 是否被其他代码修改
