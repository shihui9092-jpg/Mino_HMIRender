## 概述

**CarPaint** 是面向 Mino HMI 3D 车模的**多预设车漆切换**工具集。将 `CarPaintSwitcher` 挂在车模根节点（如 `CarRoot`）上后，系统会：

1. 自动扫描子物体中所有使用 `Mino/Unlit_CarPaint` Shader 的 Mesh；
2. 为每个匹配槽位创建**运行时材质实例**（不直接替换 Project 中的材质资源）；
3. 在多个「预设材质球」之间进行**参数插值过渡**或**立即切换**。

典型应用场景：配置页选色、颜色轮播、手势/按钮切换车漆、与 UI 列表联动等。

---

## 功能特性

| 特性 | 说明 |
|------|------|
| 自动绑定 | 递归扫描子 `Renderer`，无需手动拖每个车漆 Mesh |
| 平滑过渡 | 基于 DOTween，对颜色、浮点、向量等参数做插值 |
| Schema 驱动 | 按 Shader 属性表动态读写，Shader 增删属性时无需改 C# 硬编码 |
| 多 Mesh 同步 | 同一车模上所有车漆材质槽一并更新 |
| 贴图/Keyword 分离 | 过渡中只插值数值；结束时再切换贴图与 Shader Keywords |
| 预设 + 任意材质 | 支持按索引切换预设，也支持直接传入 `Material` |

## 依赖与环境

| 项目 | 要求 |
|------|------|
| Unity 渲染管线 | **URP**（`Mino/Unlit_CarPaint` 为 Universal Pipeline Shader） |
| 目标 Shader | `Mino/Unlit_CarPaint`（路径示例：`Assets/_MinoHMI/ArtResources/.../Unlit_CarPaint.shader`） |
| 动画库 | **DOTween**（`DG.Tweening`），用于过渡插值 |
| 命名空间 | `MinoHMI.CarPaint` |

若 Awake 时无法解析 Shader 或未找到匹配 Mesh，`CarPaintSwitcher` 会输出错误日志并 **`enabled = false`**，后续 API 调用将无效。

## 快速开始

### 1. 准备车模

- 车模车漆 Mesh 使用的材质 Shader 必须为 **`Mino/Unlit_CarPaint`**（或与预设材质相同的 Shader）。
- 将车模根节点（包含所有车漆子 Mesh 的节点）作为挂载对象，例如 `CarRoot`。

### 2. 制作预设材质

- 在 Project 中为每种颜色/效果各创建一个 **Material**，Shader 选 `Mino/Unlit_CarPaint`。
- 在 Inspector 中调好 `_CarPaintColor`、清漆、法线等参数（详见 [预设材质制作](#预设材质制作)）。
- 这些材质仅作为**参数模板**，运行时不会直接赋给 Renderer。

### 3. 挂载并配置 CarPaintSwitcher

1. 选中车模根节点 → `Add Component` → **MinoHMI / 车漆切换**。
2. 展开 **车漆预设**，设置 `Size`，为每个元素填写：
   - **Display Name**：UI 或日志用显示名；
   - **Source Material**：对应预设材质球。
3. 设置 **Default Preset Index**：进入场景时默认应用的预设索引（从 `0` 开始）。
4. 按需调整 **Transition Duration**、**Transition Ease**。

### 4. 运行时切换

```csharp
using MinoHMI.CarPaint;
using UnityEngine;

public class CarColorButton : MonoBehaviour
{
    [SerializeField] private CarPaintSwitcher paintSwitcher;
    [SerializeField] private int colorIndex;

    public void OnClick()
    {
        paintSwitcher.SwitchToPreset(colorIndex);
    }
}
```

## Inspector 配置

### 车漆预设（Paint Presets）

| 字段 | 类型 | 说明 |
|------|------|------|
| Display Name | `string` | 预设显示名称，供 UI / 日志使用 |
| Source Material | `Material` | 参考材质球，系统从中读取参数与贴图 |

数组顺序即为预设索引：`0` 为第一套，`1` 为第二套，以此类推。

### 过渡动画

| 字段 | 默认值 | 说明 |
|------|--------|------|
| Default Preset Index | `0` | 场景加载后立刻应用的预设索引；无效索引时保留当前材质状态 |
| Transition Duration | `1.2` | 过渡时长（秒），最小 `0.01` |
| Transition Ease | `InOutCubic` | DOTween 缓动类型 |

## 预设材质制作

### Shader 与路径

- **Shader 名称：** `Mino/Unlit_CarPaint`
- 工程内 Shader 资源示例：  
  `Assets/_MinoHMI/ArtResources/Models_3D/CarMod/Car/FX12-A2Car/Shader/Unlit_CarPaint.shader`

### 常用可调参数（节选）

以下为 Shader `Properties` 中的主要业务参数，制作预设时可重点调整：

| 属性名 | 类型 | 说明 |
|--------|------|------|
| `_CarPaintColor` | Color | 车漆主色 |
| `_CarPaintHSV_R` | Range | HSV 相关 |
| `_Contrast` / `_MDarkScale` / `_TopDarkScale` | Range | 明暗与对比 |
| `_Coat_IO` / `_CoatScale` / `_CoatSaturation` | Toggle/Range | 清漆层 |
| `_EnvironmentColor` / `_HDRLitTex` | Color/Cube | 环境反射 |
| `_OcclusionIO` / `_OcclusionTex` | Toggle/2D | 遮蔽 |
| `_NormalIORef` / `_NormalIOLit` / `_NormalTex` | Toggle/2D | 法线 |
| `_NoiseIO` / `_NosieTex` | Toggle/2D | 噪点 |
| `_SecrecyIO` / `_SecrecyTex` | Toggle/2D | 保密/特殊贴图 |

带 `[Toggle]`、`[Toggle(_XXX_ON)]` 的开关会映射为 **Shader Keywords**，在过渡**结束时**才从目标材质同步到运行时材质。

### 制作建议

1. **一种外观一个 Material 资源**，命名清晰（如 `CarPaint_Red.mat`、`CarPaint_Blue_Matte.mat`）。
2. 需要平滑过渡的数值（颜色、金属感、清漆强度等）在不同预设间差异越大，过渡效果越明显。
3. 若两套预设的 **贴图资源不同**（如法线、Cube、遮蔽图），过渡过程中贴图保持不变，**仅在过渡完成瞬间**切换为目标预设的贴图。
4. 若两套预设的 **Shader Keyword 不同**（如一个开清漆、一个关），Keyword 同样在过渡结束时切换，避免中途渲染状态不一致。

## 运行时 API

挂载对象上的组件类型：`CarPaintSwitcher`（`MinoHMI.CarPaint`）。

### 切换方法

| 方法 | 说明 |
|------|------|
| `SwitchToPreset(int presetIndex)` | 切换到指定预设索引，带过渡动画。索引无效、材质为空或与当前相同且未在过渡中时会忽略 |
| `SwitchToMaterial(Material sourceMaterial)` | 切换到任意材质参数；若该材质属于预设列表，会更新 `CurrentPresetIndex` |
| `ApplyPresetImmediate(int presetIndex)` | **无动画**立即应用预设（含贴图与 Keywords） |
| `SwitchToNextPreset()` | 切换到下一个预设（循环：`最后一项 → 0`）；当前无有效索引时从 `0` 开始 |

### 只读属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `CurrentPresetIndex` | `int` | 当前预设索引；未应用过有效预设时为 `-1` |
| `IsTransitioning` | `bool` | 是否正在过渡 |
| `PresetCount` | `int` | 预设数组长度 |
| `ActiveSlotCount` | `int` | 已绑定的车漆材质槽数量 |

### 行为说明

- **重复切换：** 若目标索引与 `CurrentPresetIndex` 相同且未在过渡中，`SwitchToPreset` 直接返回。
- **打断过渡：** 新的 `SwitchToPreset` / `SwitchToMaterial` 会 `Kill` 当前 Tween，从**当前运行时材质状态**开始新的过渡。
- **销毁清理：** `OnDestroy` 时停止 Tween 并 `Destroy` 所有运行时材质实例，避免泄漏。

## 事件订阅

```csharp
paintSwitcher.OnPaintTransitionStarted += index =>
{
    // index：本次切换关联的预设索引（非预设材质切换时可能为 currentPresetIndex）
    Debug.Log($"开始切换车漆，索引: {index}");
};

paintSwitcher.OnPaintTransitionCompleted += index =>
{
    // index：完成后的 CurrentPresetIndex
    Debug.Log($"车漆切换完成，当前索引: {index}");
};
```

| 事件 | 触发时机 | 参数 |
|------|----------|------|
| `OnPaintTransitionStarted` | 开始 DOTween 过渡时 | `int` 预设索引（`SwitchToMaterial` 且不在列表中时可能为当前索引） |
| `OnPaintTransitionCompleted` | 过渡结束、贴图与 Keywords 已同步后 | `int` 最终 `CurrentPresetIndex` |

请在 `OnDestroy` 中取消订阅，避免悬空引用。

## 工作原理

### 初始化（Awake）

```
解析 Shader（从预设材质或 Shader.Find("Mino/Unlit_CarPaint")）
    ↓
扫描 root 下所有 Renderer，绑定 shader 匹配的 material 槽
    ↓
创建/引用运行时 Material 实例（renderer.materials）
    ↓
若 defaultPresetIndex 有效 → ApplyPresetImmediate
否则 → 记录当前主槽位材质快照
```

### 过渡切换（SwitchToPreset / SwitchToMaterial）

```
读取当前运行时材质 → transitionFromSnapshot
读取目标 sourceMaterial → transitionToSnapshot
    ↓
DOTween 0→1：每帧 CarPaintSnapshot.Lerp → ApplyTo（不更新 Keywords）
    ↓
OnComplete：
  - ApplyTo（applyKeywords: true）
  - CopyTextures(目标材质 → 各运行时槽)
  - 更新 currentPresetIndex
```

### 属性分类处理

| 类型 | 过渡中 | 过渡结束 |
|------|--------|----------|
| Float / Range / Color / Vector / Int | 插值 | 写入目标值 |
| Texture（含 offset/scale） | 不变 | 从目标材质拷贝 |
| Shader Keywords | 保持起点 | 同步为目标材质 |

属性列表由 `CarPaintPropertySchema` 根据 Shader 反射生成并缓存，自动排除 `HideInInspector`、`PerRendererData` 等属性。

## 代码示例

### 与 UI 下拉列表联动

```csharp
using MinoHMI.CarPaint;
using UnityEngine;
using UnityEngine.UI;

public class CarPaintDropdown : MonoBehaviour
{
    [SerializeField] private CarPaintSwitcher switcher;
    [SerializeField] private Dropdown dropdown;

    private void Start()
    {
        dropdown.ClearOptions();
        var options = new System.Collections.Generic.List<string>();
        // 需在 Inspector 中保证 preset 数量与 UI 一致，或通过反射/配置表维护名称
        for (int i = 0; i < switcher.PresetCount; i++)
            options.Add($"颜色 {i}");
        dropdown.AddOptions(options);
        dropdown.onValueChanged.AddListener(switcher.SwitchToPreset);
    }

    private void OnDestroy()
    {
        dropdown.onValueChanged.RemoveListener(switcher.SwitchToPreset);
    }
}
```

### 过渡中禁用按钮

```csharp
using MinoHMI.CarPaint;
using UnityEngine;
using UnityEngine.UI;

public class CarPaintUiGate : MonoBehaviour
{
    [SerializeField] private CarPaintSwitcher switcher;
    [SerializeField] private Button[] colorButtons;

    private void OnEnable()
    {
        switcher.OnPaintTransitionStarted += _ => SetButtonsInteractable(false);
        switcher.OnPaintTransitionCompleted += _ => SetButtonsInteractable(true);
    }

    private void OnDisable()
    {
        switcher.OnPaintTransitionStarted -= _ => SetButtonsInteractable(false);
        switcher.OnPaintTransitionCompleted -= _ => SetButtonsInteractable(true);
    }

    private void SetButtonsInteractable(bool interactable)
    {
        foreach (var btn in colorButtons)
            btn.interactable = interactable;
    }
}
```

### 进入场景时静默应用默认色（无动画）

在 `CarPaintSwitcher` 上配置 **Default Preset Index** 即可在 `Awake` 中自动调用 `ApplyPresetImmediate`。

若需在其它脚本中延迟应用：

```csharp
// 例如数据加载完成后再应用
paintSwitcher.ApplyPresetImmediate(savedColorIndex);
```

### 使用非预设材质临时预览

```csharp
Material previewMat = /* 动态加载或临时创建的 Mino/Unlit_CarPaint 材质 */;
paintSwitcher.SwitchToMaterial(previewMat);
// 若 previewMat 不在预设列表中，CurrentPresetIndex 在完成后可能保持原值
```

## 常见问题

### Q1：Console 报「无法识别车漆 Shader」

**原因：** 预设数组为空，且工程中找不到名为 `Mino/Unlit_CarPaint` 的 Shader。

**处理：**
- 至少为一个预设指定有效的 `Source Material`；或
- 确认 Shader 已导入且名称 exactly 为 `Mino/Unlit_CarPaint`。

### Q2：报「未找到使用 xxx 的车漆 Mesh」

**原因：** 子物体中没有材质的 Shader 与解析出的目标 Shader 一致。

**处理：**
- 检查车漆 Mesh 的 Material 是否使用 `Mino/Unlit_CarPaint`；
- 确认 `CarPaintSwitcher` 挂在包含这些 Renderer 的根节点下；
- 子物体可为 **Inactive**，扫描包含 `includeInactive: true`。

### Q3：切换无视觉效果

**检查：**
- 组件是否因 Awake 失败被 `enabled = false`；
- 预设 `Source Material` 是否为空；
- 多套预设参数是否实际相同；
- 是否在过渡未完成时又被相同预设打断。

### Q4：过渡中贴图/开关效果「跳变」

**说明：** 设计如此。贴图与 Shader Keywords 仅在过渡**结束**时更新。若需要贴图也渐变，需自行扩展 `CarPaintSnapshot`（当前版本不支持贴图插值）。

### Q5：编辑器里改了共享材质，Play 后不对

**说明：** 运行时使用 `renderer.materials` 创建的**实例**，不会写回 Project 中的共享材质。请在预设 Material 资源上调色，或通过 API 切换。

### Q6：多个 CarPaintSwitcher 在同一车模上

`CarPaintSwitcher` 带有 `[DisallowMultipleComponent]`，同一 GameObject 只能挂一个。整车只需一个 Switcher 挂在根节点即可。

## 限制与注意事项

1. **仅支持单一目标 Shader 族**  
   一次绑定只处理与「预设材质 / 默认 Shader」相同 Shader 的槽位；车模上其它 Shader 的材质不会被修改。

2. **运行时材质实例**  
   会额外占用内存；销毁 Switcher 或场景卸载时会清理。避免在 Play 模式下误将实例材质保存为资产。

3. **贴图不参与插值**  
   不同预设若贴图差异大，过渡末段可能出现一次贴图切换，属预期行为。

4. **整型属性插值**  
   Int 类型通过 `Round(Lerp)` 近似，适合少量枚举式参数，不适合复杂位标志的精细过渡。

5. **DOTween 依赖**  
   确保项目已正确导入 DOTween；过渡时长过短（&lt; 0.01）在 Inspector 中会被限制为最小 `0.01`。

6. **线程安全**  
   所有 API 须在 Unity 主线程调用。

7. **扩展维护**  
   若更换车漆 Shader，需保证新 Shader 属性仍可通过 `Shader.GetPropertyCount` 枚举；隐藏属性遵循 Unity `ShaderPropertyFlags` 规则。
