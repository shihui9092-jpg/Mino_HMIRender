# 子按钮预制体问题排查指南

## 症状
子按钮没有正确调用预制体的按钮资源效果（样式、动画、交互等）。

## 可能的原因

### 1. 预制体模板引用缺失（最常见）
**检查方法：**
- 在 Unity 场景中选中 `DotweenUguiMenuTemplate` 对象
- 查看 `DotweenUguiMenuController` 组件的 Inspector
- 检查 **Sub Menu Button Template** 字段是否已赋值

**解决方案（推荐）：**
- 在 `DotweenUguiMenuController` 组件中，将 `Assets/_MinoHMI/Prefabs/DOTweenUGUI/SubMenuButton_Template.prefab` 拖入 **Sub Menu Button Template** 字段
- **注意：应该拖入 Project 窗口中的预制体文件，而不是 Hierarchy 中的场景对象**

**解决方案（备选）：**
如果 Controller 未配置，也可以在 `SubMenuPanel` 对象的 `DotweenUguiSubMenuPanel` 组件中配置 **Sub Button Template** 字段

### 2. 预制体模板引用指向错误对象
**检查方法：**
- 运行游戏后查看 Console
- 查找 `[DotweenUguiSubMenuPanel]` 开头的日志信息
- 如果看到 "Rebuild 终止"，说明引用有问题

**解决方案：**
1. 停止游戏
2. 在 Project 窗口找到 `SubMenuButton_Template.prefab`
3. 重新拖入 `Sub Button Template` 字段
4. 确保引用显示为 `SubMenuButton_Template (DotweenUguiMenuItemView)`

### 3. contentRoot 引用错误
**症状：**
Console 显示 "contentRoot 不是场景实例"

**解决方案：**
1. 选中 `SubMenuPanel` 对象
2. 在 `DotweenUguiSubMenuPanel` 组件中
3. 清空 **Content Root** 字段（设为 None）
4. 脚本会自动使用当前 Transform

### 4. 预制体模板本身有问题
**检查方法：**
- 在 Project 窗口双击打开 `SubMenuButton_Template.prefab`
- 检查根节点是否有以下组件：
  - `RectTransform`
  - `Image`（按钮背景）
  - `Button`
  - `CanvasGroup`（用于淡入动画）
  - `DotweenUguiMenuItemView`（脚本）
- 检查是否有 `Label` 子对象包含 `Text` 或 `TMP_Text` 组件

**解决方案：**
如果缺少任何组件，参考 `自定义按钮指南.md` 第五节重新配置。

### 5. 实例化后的按钮样式丢失
**可能原因：**
- 预制体模板的 Image Sprite 未赋值
- Button 的 Transition 设置为 None
- 材质或着色器问题

**检查方法：**
运行游戏后，在 Hierarchy 中展开 `SubMenuPanel`，检查生成的 `SubButton_0_xxx` 对象：
- 是否包含所有预制体的组件
- Image 的 Sprite 字段是否有值
- Button 的 Transition 是否正确

## 调试步骤

### 第一步：启用详细日志
代码已包含调试日志。运行游戏后，Console 会显示：
```
[DotweenUguiSubMenuPanel] 开始生成 N 个子按钮，模板: xxx
[DotweenUguiSubMenuPanel] 已创建子按钮 [0]: SubButton_0_xxx, 文本: xxx
```

### 第二步：检查实例化结果
1. 运行游戏
2. 在 Hierarchy 中找到 `SubMenuPanel`
3. 展开查看生成的子按钮
4. 选中一个子按钮，在 Inspector 中对比它与预制体模板的组件差异

### 第三步：手动测试预制体
1. 停止游戏
2. 将 `SubMenuButton_Template.prefab` 直接拖入场景
3. 设置为 Active
4. 调整 Canvas 位置使其可见
5. 运行游戏，点击这个测试按钮
6. 如果测试按钮也没有效果，说明预制体本身有问题

## 常见配置错误

| 问题 | 表现 | 解决 |
|------|------|------|
| 按钮无背景 | 只看到文字，没有按钮形状 | 检查 Image 组件的 Sprite 字段 |
| 按钮不响应点击 | 点击无反应，不变色 | 检查 Button 组件是否启用，Interactable 勾选 |
| 按钮无点击缩放 | 点击无视觉反馈 | 检查 DOTween 是否正确导入 |
| 文字不显示 | 按钮存在但看不到文字 | 检查 Text/TMP_Text 组件及字体 |
| 子按钮无淡入动画 | 子按钮瞬间出现 | 检查 CanvasGroup 组件 |

## 预制体正确配置示例

### SubMenuButton_Template 结构：
```
SubMenuButton_Template (GameObject)
├─ RectTransform (200x40)
├─ Image (Sprite: 按钮背景图)
├─ Button (Transition: Color Tint)
├─ CanvasGroup (Alpha: 1, Interactable: true)
├─ DotweenUguiMenuItemView (脚本)
└─ Label (子对象)
   ├─ RectTransform (填充父对象)
   └─ Text 或 TextMeshProUGUI (文本组件)
```

### Inspector 字段配置：
**DotweenUguiMenuItemView:**
- `Tmp Label`: 指向 Label 子对象的 TMP_Text
- 或 `Legacy Label`: 指向 Label 子对象的 Text
- 其他字段保持默认

## 验证清单

运行游戏前请确认：
- [ ] `SubMenuPanel` 的 `Sub Button Template` 字段已赋值
- [ ] 引用的是 Project 中的预制体，不是场景对象
- [ ] `SubMenuButton_Template.prefab` 包含所有必需组件
- [ ] 预制体根节点是 Inactive（已禁用）
- [ ] Button 的 On Click () 事件列表为空
- [ ] CanvasGroup 存在且 Alpha = 1

运行游戏后检查：
- [ ] Console 无错误信息
- [ ] Console 显示 "开始生成 X 个子按钮"
- [ ] Hierarchy 中可以看到生成的 `SubButton_0_xxx` 对象
- [ ] 生成的子按钮继承了预制体的所有组件
- [ ] 子按钮文字正确显示
- [ ] 点击主菜单后子按钮有淡入动画
