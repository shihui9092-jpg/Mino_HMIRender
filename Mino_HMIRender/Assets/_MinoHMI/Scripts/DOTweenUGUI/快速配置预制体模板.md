# 快速配置预制体模板指南

## 问题描述
如果您发现子按钮的样式和主菜单按钮不一致，或者子按钮使用了默认的灰色按钮而不是自定义预制体，请按照以下步骤配置。

## 一键配置步骤（推荐方式）

### 步骤 0：清理旧的场景模板对象（如果有）
如果您的场景中 `MainMenuRoot` 或 `SubMenuPanel` 下已经有旧的按钮模板对象（如 `MainMenuButtonTemplate` 或 `SubMenuButtonTemplate`），脚本会在运行时**自动隐藏**它们，防止布局混乱。

**可选操作：** 您也可以手动删除这些旧的场景模板对象，只保留通过 Project 预制体引用的方式。

### 步骤 1：自动清理旧的场景模板对象
脚本会根据您的配置方式，在运行时**自动清理**场景中的旧模板对象：

#### 情况 A：使用 Project 预制体（推荐）
如果您在 Controller 中配置了 Project 预制体：
- **删除所有**场景中的旧模板对象
- 场景保持干净，只有动态生成的按钮

**Console 显示：**
```
[DotweenUguiSubMenuPanel] 使用 Project 预制体作为模板，将删除所有场景中的旧模板对象。
[DotweenUguiSubMenuPanel] 已删除全部 N 个场景模板对象。
```

#### 情况 B：使用场景对象作为模板
如果您的 `subButtonTemplate` 引用指向场景中的对象：
- **保留该场景对象**作为模板（隐藏状态）
- **删除其他的**多余对象

**Console 显示：**
```
[DotweenUguiSubMenuPanel] 使用场景对象作为模板，将保留: SubMenuButtonTemplate
[DotweenUguiSubMenuPanel] 已删除 N 个多余的场景模板对象，保留 1 个作为模板。
```

**推荐做法：** 使用 **Project 预制体**作为模板，场景中不保留任何模板对象

### 步骤 2：准备预制体文件
确保以下预制体文件存在于 Project 窗口：
- `Assets/_MinoHMI/Prefabs/DOTweenUGUI/MainMenuButton_Template.prefab`
- `Assets/_MinoHMI/Prefabs/DOTweenUGUI/SubMenuButton_Template.prefab`

### 步骤 2：在 MenuController 统一配置（推荐）

**DotweenUguiMenuTemplate 已内置嵌套 `MainMenuRoot.prefab` 与 `SubMenuRoot.prefab` 实例。** 若在自定义场景中手动搭建，请确保：

- **结构槽位**（Main Menu Root / Grid / Sub Menu Panel）→ 拖 **Hierarchy 嵌套实例**
- **按钮 Template 槽位** → 拖 **Project 中的 .prefab 文件**

1. 在场景 Hierarchy 中选中 `DotweenUguiMenuTemplate` 对象
2. 找到 `DotweenUguiMenuController` 组件
3. 在 Inspector 的 **结构引用** 区域：

| 字段名称 | 如何配置 | 说明 |
|---------|---------|------|
| **Main Menu Button Template** | 从 Project 拖入 `MainMenuButton_Template.prefab` | 主菜单按钮样式 |
| **Sub Menu Button Template** | 从 Project 拖入 `SubMenuButton_Template.prefab` | **子菜单按钮样式（重要！）** |

**关键要点：**
- ✅ 必须从 **Project 窗口**拖入预制体文件
- ❌ 不要从 Hierarchy 窗口拖入场景对象
- ✅ 引用应显示为 `xxxTemplate (DotweenUguiMenuItemView)`
- ❌ 如果显示为 `None`，说明未正确配置

### 步骤 4：验证配置
运行游戏，检查：
- [ ] 主菜单按钮使用了 `MainMenuButton_Template` 的样式
- [ ] 子菜单按钮使用了 `SubMenuButton_Template` 的样式
- [ ] Console 显示：`[DotweenUguiSubMenuPanel] 使用 MenuController 指定的子按钮模板: SubMenuButton_Template`

## 备选配置方式（不推荐）

如果您不想在 Controller 层级配置，也可以在 SubMenuPanel 组件中单独配置：

1. 在 Hierarchy 中展开 `DotweenUguiMenuTemplate`
2. 选中 `SubMenuPanel` 子对象（通常名为 `SubMenuRoot`）
3. 找到 `DotweenUguiSubMenuPanel` 组件
4. 在 **结构引用** 区域的 **Sub Button Template** 字段
5. 从 Project 拖入 `SubMenuButton_Template.prefab`

**注意：** 如果 Controller 和 SubMenuPanel 都配置了模板，**Controller 的配置优先级更高**。

## 常见错误

### 错误 1：引用了场景对象而非预制体
**症状：** 子按钮样式正确，但 Console 报错 `Cannot instantiate objects with a parent which is persistent`

**原因：** 您从 Hierarchy 拖入了场景中的模板对象，而不是 Project 中的预制体文件

**解决：** 
1. 清空该引用字段（设为 None）
2. 从 Project 窗口重新拖入预制体文件

### 错误 2：模板字段为空
**症状：** 子按钮使用默认的灰色样式

**原因：** `Sub Menu Button Template` 字段未配置

**解决：** 按照上述步骤 2 配置

### 错误 3：预制体文件不存在
**症状：** 无法找到预制体文件

**解决：** 参考 `自定义按钮指南.md` 第四节创建预制体

## 配置优先级说明

模板引用的查找顺序（从高到低）：
1. **DotweenUguiMenuController.subMenuButtonTemplate**（在 Controller 组件配置）
2. **DotweenUguiSubMenuPanel.subButtonTemplate**（在 SubMenuPanel 组件配置）
3. **自动查找**：从 SubMenuPanel 子对象中查找第一个 `DotweenUguiMenuItemView`（可能不准确）

推荐使用方式 1，在 Controller 层级统一管理所有模板引用。

## 完整配置检查清单

在运行游戏前，请确认以下所有项：

**预制体文件：**
- [ ] `MainMenuButton_Template.prefab` 存在于 Project
- [ ] `SubMenuButton_Template.prefab` 存在于 Project
- [ ] 两个预制体根节点都是 Inactive（未激活）

**Controller 配置：**
- [ ] `Main Menu Button Template` 已赋值（指向 Project 预制体）
- [ ] `Sub Menu Button Template` 已赋值（指向 Project 预制体）
- [ ] 两个字段都不是 None

**运行时检查：**
- [ ] Console 无错误信息
- [ ] 主菜单和子菜单按钮样式一致（都使用自定义预制体）
- [ ] 按钮有正确的图片、文字、动画效果

## 需要帮助？

如果按照以上步骤配置后仍有问题，请检查：
1. Unity Console 的完整错误信息
2. Hierarchy 中生成的按钮对象是否包含预制体的所有组件
3. 预制体本身是否配置正确（参考 `自定义按钮指南.md`）
