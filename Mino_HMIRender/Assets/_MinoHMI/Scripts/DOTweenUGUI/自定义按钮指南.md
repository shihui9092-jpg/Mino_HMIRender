# DOTweenUGUI — 自定义按钮详细指南

本文说明如何**不用运行时自动生成的灰底按钮**，改为使用你自己设计的图片、字体、圆角、图标等样式，并正确接到菜单数据与 DOTween 动画上。

---

## 一、先搞清楚「模板」是什么

本系统**不会**在场景里手动摆一排按钮，而是：

1. 你做一个 **按钮预制体（Template）**，挂在 Inspector 里；
2. 进入 Play 后，代码按 `Menu Data List` **Instantiate 多份**；
3. 每份调用 `Setup(菜单文案, 点击回调)` 写入 `menuName` / `buttonName`。

因此「自定义按钮」= **自定义 Template 预制体** + **在 Controller 里替换引用**。

| 模板字段（Inspector） | 挂在哪 | 用途 |
|---------------------|--------|------|
| **Main Menu Button Template** | `DotweenUguiMenuController` | 主菜单 Tab 按钮 |
| **Sub Button Template** | `DotweenUguiSubMenuPanel` | 子菜单按钮 |

主、子菜单**可以各用不同预制体**（例如主菜单大横条、子菜单小方格）。

---

## 二、按钮预制体必须满足的组件

根物体上建议具备以下组件（顺序不限）：

| 组件 | 是否必须 | 作用 |
|------|----------|------|
| `RectTransform` | 必须 | 布局与 DOTween 位移 |
| `Button` | 必须 | 点击检测；**不要在 Inspector 里额外挂 OnClick** |
| `DotweenUguiMenuItemView` | 必须 | 文案、点击缩放、淡入淡出 |
| `CanvasGroup` | 子菜单强烈建议 | 子菜单出现时的 **Fade**；没有则淡入动画无效 |
| `Image`（或其它 Graphic） | 建议 | 作为 `Button.targetGraphic` 显示底图 |

文案二选一（可只用一种）：

| 文案组件 | 字段名（MenuItemView） | 说明 |
|----------|------------------------|------|
| `TextMeshPro - Text (UI)` | **Tmp Label** | 推荐新项目使用 |
| `Text`（Legacy） | **Legacy Label** | 旧版 UGUI 文本 |

未手动拖引用时，会在 **子物体** 上 `GetComponentInChildren` 自动查找。

## 三、推荐 Hierarchy 结构（TMP 版）

在 Project 窗口空白处：**Create → UI → Button - TextMeshPro** 会得到接近结构，再按下面调整。

### 3.1 主菜单按钮示例

```
MainMenuButton_Template          ← 根：RectTransform + Image + Button + CanvasGroup + DotweenUguiMenuItemView
├── Background                   ← 可选，Image 已在根上可省略
├── Icon                         ← 可选，Image，装饰图标
└── Label                        ← TMP_Text，显示 menuName
```

### 3.2 子菜单按钮示例

```
SubMenuButton_Template           ← 同上，尺寸可略小
└── Label                        ← TMP_Text，显示 buttonName
```

### 3.3 尺寸建议

| 项目 | 建议值 | 说明 |
|------|--------|------|
| 根 `RectTransform.sizeDelta` | 主：200×56，子：160×48 | 需与 Grid **Cell Size** 协调 |
| `GridLayoutGroup.cellSize` | ≥ 按钮 sizeDelta | 在 `MainMenuRoot` / `SubMenuRoot` 上改 |
| Label 锚点 | Stretch 全铺满 | 方便长文案 |

## 四、手把手：从零做一个 TMP 主菜单按钮

### 步骤 1：创建预制体

1. 在 Hierarchy 的 **Canvas** 下：**UI → Button - TextMeshPro**，命名为 `MainMenuButton_Template`。
2. 调整根节点 **Width / Height**（如 200×56）。
3. 替换 **Image** 的 Sprite / 颜色为你项目 UI 规范。

### 步骤 2：挂接 DotweenUguiMenuItemView

1. 选中根物体 → **Add Component** → 搜索 `DotweenUguiMenuItemView`。
2. 在组件上检查引用（可点右上角 **⋮ → Reset** 后自动填充部分字段）：

| 字段 | 拖入对象 |
|------|----------|
| Button | 根物体上的 Button |
| Rect Transform | 根物体 |
| Canvas Group | 根物体（若无则 Add Component） |
| Tmp Label | 子物体 `Text (TMP)` |
| Legacy Label | 留空（用 TMP 时） |

3. **点击反馈**（可选调）：
   - Click Scale：按下放大比例，默认 `1.08`
   - Click Duration：缩放时长，默认 `0.14`

### 步骤 3：清理多余监听

1. 选中 **Button** 组件。
2. **On Click ()** 列表保持 **空**（不要拖任何方法）。  
   点击逻辑由 `DotweenUguiMenuItemView` 内部 `onClick` 统一处理，再转到菜单控制器。

### 步骤 4：模板占位文案

把 TMP 默认文字改成 `占位` 即可；运行后会被 `menuName` 覆盖。

### 步骤 5：存为 Prefab

1. 将 `MainMenuButton_Template` 拖到  
   `Assets/_MinoHMI/Prefabs/DOTweenUGUI/`  
2. 删除 Hierarchy 里的实例（保留 Prefab 即可）。

### 步骤 6：禁用模板物体

预制体根节点 **取消勾选**（Inactive）。  
运行时 `BuildMainMenu` 会 `Instantiate` 后再 `SetActive(true)`，模板本身始终保持隐藏。

## 五、接到菜单控制器（嵌套结构预制体 + 按钮模板）

### 5.1 推荐 Hierarchy（嵌套预制体）

```
DotweenUguiMenuTemplate
├── MainMenuRoot（嵌套 MainMenuRoot.prefab 实例）
│   └── RectTransform + GridLayoutGroup（同一节点，扁平结构）
└── SubMenuRoot（嵌套 SubMenuRoot.prefab 实例）
    └── RectTransform + GridLayoutGroup + DotweenUguiSubMenuPanel（同一节点）
```

**运行时动态按钮**会生成在上述两个容器下，名称形如 `MainButton_0_xxx`、`SubButton_0_xxx`，并自动打上 `DotweenUguiMenuRuntimeItem` 标记；嵌套预制体中的静态装饰不会被删除。

### 5.2 槽位引用规则（重要）

| 槽位 | 应指向 | 禁止 |
|------|--------|------|
| Main Menu Root | Hierarchy 中 **MainMenuRoot 嵌套实例** 的 RectTransform | Project 预制体资源 |
| Main Menu Grid | 同上实例上的 GridLayoutGroup | 其他节点上的 Grid |
| Sub Menu Panel | **SubMenuRoot 嵌套实例** 上的 DotweenUguiSubMenuPanel | Project 预制体资源 |
| Main Menu Button Template | Project 中 `MainMenuButton_Template.prefab` | Hierarchy 场景对象 |
| Sub Menu Button Template | Project 中 `SubMenuButton_Template.prefab` | Hierarchy 场景对象 |

当 **Main Menu Root + Sub Menu Panel** 均已赋值时，进入**作者结构模式**：脚本只校验引用，**不会**自动创建节点、不会 AddComponent、不会修改 Grid 参数。

### 5.3 接线步骤

1. 打开 `DotweenUguiMenuTemplate`，将 `MainMenuRoot.prefab`、`SubMenuRoot.prefab` 拖为子物体（嵌套实例）。
2. 选中根物体 **Dotween Ugui Menu Controller**，填写结构引用：

| 字段 | 赋值 |
|------|------|
| Main Menu Root | 嵌套 `MainMenuRoot` 实例 |
| Main Menu Grid | 同上实例的 GridLayoutGroup |
| Main Menu Button Template | Project 中主按钮 `.prefab` |
| Sub Menu Panel | 嵌套 `SubMenuRoot` 实例上的 DotweenUguiSubMenuPanel |
| Sub Menu Button Template | Project 中子按钮 `.prefab` |

3. 嵌套 `SubMenuRoot` 上的 **Dotween Ugui Sub Menu Panel**（扁平结构）：

| 字段 | 赋值 |
|------|------|
| Content Root | 自身 RectTransform |
| Content Grid | 自身 GridLayoutGroup |
| Sub Button Template | 可与 Controller 一致，或留空由 Controller 传入 |

4. **不要**在 MainMenuRoot / SubMenuRoot 下放按钮模板场景对象；按钮模板只引用 Project 预制体。

### 5.4 兜底模式

若 **Main Menu Root 或 Sub Menu Panel 留空**，脚本会在运行时自动创建默认灰色结构（仅用于快速测试，不推荐与嵌套预制体混用）。

### 方式 B：仅替换主按钮、子按钮仍用默认

只填 **Main Menu Button Template**，`Sub Menu Panel` 留空 → 子菜单仍会自动生成默认灰按钮。

## 六、调整排版（GridLayoutGroup）

### 主菜单（横向一排）

在 `MainMenuRoot` → **Grid Layout Group**：

| 属性 | 示例 |
|------|------|
| Cell Size | 200 × 56（与按钮 sizeDelta 一致） |
| Spacing | 16 × 0 |
| Constraint | Fixed Row Count = 1 |

### 子菜单（多列网格）

在 `SubMenuRoot` → **Grid Layout Group**：

| 属性 | 示例 |
|------|------|
| Cell Size | 160 × 48 |
| Spacing | 12 × 12 |
| Constraint | Fixed Column Count = 3 |

子菜单 **出现动画** 依赖 Grid 排好的 X 坐标；改 Cell Size 后若动画错位，可适当调 `DotweenUguiSubMenuPanel` 的 **Appear From Left Offset**。

---

## 七、子菜单出现动画参数

在 `DotweenUguiSubMenuPanel` 上：

| 字段 | 作用 |
|------|------|
| Appear From Left Offset | 从目标 X 左侧多少像素滑入 |
| Appear Move Duration | 滑动时长 |
| Appear Fade Duration | 淡入时长（需按钮有 CanvasGroup） |
| Item Stagger | 每个按钮延迟间隔 |
| Appear Ease | 缓动曲线 |

动画期间会 `SetInteractable(false)`，结束后才可点击。

---

## 八、菜单数据如何驱动自定义样式

自定义预制体**只决定外观**；**数量与文字**仍由数据决定。

```text
Menu Data List[0]
  menuName     → 主按钮 Label 文本
  subButtons[i].buttonName → 第 i 个子按钮 Label 文本
```

示例：

| menuName | subButtons[].buttonName |
|----------|-------------------------|
| 车漆 | 珍珠白、曜石黑、金属蓝 |
| 内饰 | 黑色真皮、米色织物 |

无需为每个颜色单独做预制体；**一个子按钮 Template** 复用即可。

---

## 九、Legacy Text 版按钮（不用 TMP）

若项目未装 TextMeshPro：

1. **UI → Button** 创建；
2. 子物体用 **UI → Text** 作为 Label；
3. `DotweenUguiMenuItemView` 只填 **Legacy Label**；
4. 字体在 Text 上指定项目 Font Asset，**不要**依赖运行时 `LegacyRuntime.ttf`。

## 十、带图标 + 文字（进阶结构）

```
CustomMenuButton
├── IconImage          ← Image，左侧固定宽 32
└── Label              ← TMP_Text，锚点 Left，offset 留出图标位
```

注意：

- 只有名为 `Label` 的 TMP 会被自动找到；若多个 TMP，请在 Inspector **手动指定 Tmp Label**。
- 图标 Sprite 在预制体里写死；若要根据数据换图，需扩展 `DotweenUguiMenuItemView`（例如 `SetIcon(Sprite)`），当前版本未内置。

## 十一、子按钮出现动画

在 `SubMenuPanel` 组件中的 **子菜单出现动画** 区域：

| 参数 | 说明 |
|------|------|
| **Appear From Left Offset** | 子按钮从左侧出现的偏移距离（默认 80） |
| **Appear Move Duration** | 移动动画持续时间 |
| **Appear Fade Duration** | 淡入动画持续时间 |
| **Item Stagger** | 子按钮依次出现的时间间隔 |

调整 `Appear From Left Offset` 可控制子按钮出现时的初始偏移位置。

## 十二、自检清单（Play 前）

- [ ] 模板预制体根节点 **已 Inactive**
- [ ] 根物体有 `Button` + `DotweenUguiMenuItemView`
- [ ] Button 的 **On Click ()** 为空
- [ ] Tmp Label / Legacy Label 已拖好或子节点可自动找到
- [ ] 子按钮模板有 **CanvasGroup**（要淡入动画）
- [ ] Controller 已拖 **Main Menu Button Template**
- [ ] SubMenuPanel 已拖 **Sub Button Template**
- [ ] Grid **Cell Size** 与按钮尺寸匹配
- [ ] Play 后按钮文字为 `menuName` / `buttonName`，不是「占位」

## 十三、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| Play 后按钮完全不生成 | 结构槽位未指向嵌套实例，或误拖 Project 预制体资源 | 结构引用拖 Hierarchy 嵌套实例；按钮 Template 拖 Project `.prefab` |
| 出现两套 MainMenuRoot / SubMenuRoot | 已嵌套预制体但 Controller 槽位为空 | 填齐 Main Menu Root + Sub Menu Panel，进入作者结构模式 |
| 嵌套预制体内装饰被删 | 旧版全树扫描 MenuItemView（已修复） | 更新脚本；运行时仅清理带 `DotweenUguiMenuRuntimeItem` 的对象 |
| 仍是灰色自动按钮 | Template 引用为空 | 按第五节填齐引用 |
| 文字不更新 | 未挂 TMP/Text 引用 | 拖 Tmp Label 或放子节点 Text |
| 子菜单无淡入 | 无 CanvasGroup | 根节点 Add Component |
| 点击无缩放 | 缺少 RectTransform 或 DOTween 未导入 | 检查 Console |
| 点了两次才切换 | Button OnClick 与脚本重复绑定 | 清空 Button OnClick |
| 排版挤在一起 | cellSize 小于按钮实际尺寸 | 调大 Grid Cell Size |
| 子菜单动画飞错位置 | 改 Grid 后未重进 Play | 重新 Play |

## 十四、与车漆桥接配合

自定义按钮**不影响**事件与桥接：仍配置 `Menu Data List` 的 `menuId` / `buttonId`，以及 `DotweenUguiCarPaintMenuBridge` 的映射表。  
详见同目录 **车漆菜单接入指南.md**。
