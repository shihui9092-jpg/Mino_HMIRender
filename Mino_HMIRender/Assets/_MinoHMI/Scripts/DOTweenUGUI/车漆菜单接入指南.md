# DOTweenUGUI × 车漆切换 — 详细接入指南

本文说明如何在场景中把 **DOTweenUGUI 两级菜单** 与 **CarPaintSwitcher 车漆切换** 接在一起，并讲清楚 **回调事件**、**子按钮如何触发** 的完整链路。

---

## 一、先理解事件是怎么触发的（不必给每个子节点单独挂脚本）

很多人误以为要在 Hierarchy 里给每个子按钮单独拖 `OnClick`。本模块 **不需要** 这样做。

### 1.1 运行时层级（进入 Play 后自动生成）

若预制体未手动指定 `Main Menu Root` 等引用，`DotweenUguiMenuController` 会在 `Awake` 里自动创建：

```
Canvas
└── DotweenUguiMenuTemplate          ← DotweenUguiMenuController
    ├── MainMenuRoot                 ← GridLayoutGroup，主按钮容器
    │   ├── MainButton_0_CarPaint    ← 运行时 Instantiate（示例名）
    │   ├── MainButton_1_Interior
    │   └── MainMenuButtonTemplate   ← 模板，隐藏
    └── SubMenuRoot                  ← DotweenUguiSubMenuPanel
        ├── SubButton_0_Paint_0      ← 切换主菜单时动态生成
        ├── SubButton_1_Paint_1
        └── SubMenuButtonTemplate    ← 模板，隐藏
```

### 1.2 点击链路（从按钮到 UnityEvent）

```
【主菜单】用户点击 MainButton
    → DotweenUguiMenuItemView.PlayClickFeedback（缩放动画）
    → DotweenUguiMenuController.SelectMainMenu(index)
    → 触发 On Main Menu Selected（menuId, menuName）
    → SubMenuPanel.Rebuild + PlayAppearAnimation（子按钮滑入）

【子菜单】用户点击 SubButton
    → DotweenUguiMenuItemView.PlayClickFeedback
    → Rebuild 时注册的 lambda
    → 触发 On Sub Menu Button Clicked（mainMenuId, mainMenuName, subButtonId, subButtonName）
    → 你的桥接 / Inspector 监听 / 自定义脚本
    → CarPaintSwitcher.SwitchToPreset(index)
```

**要点：**

- 子按钮的点击在 `Rebuild` 时由代码统一绑定，**只配置数据里的 `buttonId`**，不用给每个子 GameObject 挂独立监听器。
- 对外暴露的是 `DotweenUguiMenuController` 上的两个 **UnityEvent**，在 Inspector 里显示为：
  - **On Main Menu Selected**
  - **On Sub Menu Button Clicked**

## 三、分步配置（推荐完整走一遍）

### 步骤 1：配置车漆预设（车模侧）

1. 选中车模根节点（如 `CarRoot`）。
2. **Add Component** → 搜索 **车漆切换**（`CarPaintSwitcher`）。
3. 展开 **车漆预设 (Paint Presets)**，设置 **Size** = 颜色数量（例如 3）。
4. 每一项填写：
   - **Display Name**：仅备注，桥接不读取此项。
   - **Source Material**：对应颜色的参考材质球（`Mino/Unlit_CarPaint`）。
5. **Default Preset Index**：进场景默认显示的颜色下标（通常 `0`）。
6. 点击 **Play**，确认默认颜色正确、Console 无红色报错。

**预设下标与后续映射的关系：**

| paintPresets 下标 | 含义 |
|-------------------|------|
| 0 | 第 1 个颜色 |
| 1 | 第 2 个颜色 |
| 2 | 第 3 个颜色 |

---

### 步骤 2：放入菜单 UI

1. 在 **Project** 窗口打开：  
   `Assets/_MinoHMI/Prefabs/DOTweenUGUI/DotweenUguiMenuTemplate.prefab`
2. 将预制体拖到场景 **Canvas** 下（作为 Canvas 子物体）。
3. 建议重命名为 `HMI_Menu`（可选）。
4. 调整 **Rect Transform** 铺满或摆到合适位置。

---

### 步骤 3：配置菜单数据（决定主/子按钮显示与 ID）

选中场景中的菜单对象，在 **Dotween Ugui Menu Controller** 组件里找到 **菜单数据 (Menu Data List)**。

#### 示例：一个「车漆」主菜单 + 三个颜色子按钮

点击 **Menu Data List** → **Size** = `1`（若还要「内饰」等，可设为 2、3…）。

**Element 0（车漆主菜单）：**

| 字段 | 填写值 | 说明 |
|------|--------|------|
| Menu Id | `CarPaint` | **逻辑 ID**，桥接过滤用，区分不同主 Tab |
| Menu Name | `车漆` | 主按钮上显示的文字 |
| Sub Buttons → Size | `3` | 子按钮个数 |
| Sub Buttons[0] → Button Id | `Paint_0` | **逻辑 ID**，必须与桥接映射表一致 |
| Sub Buttons[0] → Button Name | `珍珠白` | 子按钮显示文字 |
| Sub Buttons[1] → Button Id | `Paint_1` | |
| Sub Buttons[1] → Button Name | `曜石黑` | |
| Sub Buttons[2] → Button Id | `Paint_2` | |
| Sub Buttons[2] → Button Name | `金属蓝` | |

**Default Main Menu Index**：`0`（启动时默认选中「车漆」并展开子菜单）。

> **Menu Id / Button Id 与 Button Name 的区别**  
> - `menuId`、`buttonId`：代码、桥接、日志里用的 **字符串键**，改名不影响显示。  
> - `menuName`、`buttonName`：仅 UI 文案。

#### 示例：多主菜单（车漆 + 内饰）

| Element | Menu Id | Menu Name | 子按钮示例 |
|---------|---------|-----------|------------|
| 0 | `CarPaint` | 车漆 | Paint_0, Paint_1… |
| 1 | `Interior` | 内饰 | Seat_0, Wheel_0… |

车漆桥接只会响应 `menuId == CarPaint` 的子按钮点击（见步骤 5）。

---

### 步骤 4：添加车漆桥接组件

1. 场景中新建空物体，命名为 `CarPaintMenuBridge`（或挂在菜单同一物体上）。
2. **Add Component** → **MinoHMI/DOTweenUGUI/车漆菜单桥接**（`DotweenUguiCarPaintMenuBridge`）。
3. 填写 Inspector：

| 字段 | 操作 |
|------|------|
| **Menu Controller** | 拖入场景里的 `DotweenUguiMenuController` 所在物体 |
| **Car Paint Switcher** | 拖入车模上的 `CarPaintSwitcher` |
| **Car Paint Main Menu Id** | 填 `CarPaint`（与步骤 3 的 Menu Id 完全一致） |
| **Paint Bindings** | 见下表 |

**Paint Bindings 示例（与步骤 3 一一对应）：**

| Sub Button Id | Preset Index |
|---------------|--------------|
| Paint_0 | 0 |
| Paint_1 | 1 |
| Paint_2 | 2 |

**快捷生成绑定：**  
在桥接组件标题栏 **⋮** 或右键组件 → **从车漆预设生成绑定列表**（需先拖好 `Car Paint Switcher`）。会自动生成 `Paint_0`…`Paint_N`，但仍需在步骤 3 里把子按钮 `buttonId` 改成相同名字。

---

### 步骤 5：挂载回调的两种方式

桥接脚本在 `OnEnable` 时会 **自动** 订阅菜单事件，多数情况 **不必** 再手动绑 UnityEvent。下面两种方式 **二选一** 即可，不要重复绑两次（否则会切换两次颜色）。

---

#### 方式 A：自动代码订阅（推荐，步骤 4 做完即可）

`DotweenUguiCarPaintMenuBridge` 内部代码：

```csharp
menuController.SubMenuButtonClicked.AddListener(HandleSubMenuButtonClicked);
```

**你需要做的：** 仅完成步骤 1～4，保证场景里桥接组件 **启用 (勾选)**，且 `Menu Controller`、`Car Paint Switcher` 已赋值。

**验证：** Play → 点击子按钮「珍珠白」→ 车模应过渡到 `paintPresets[0]` 对应颜色。

---

#### 方式 B：Inspector 手动挂 UnityEvent（可视化、适合不用桥接时）

适合：想自己写接收方法，或临时调试事件是否触发。

1. 选中挂有 **Dotween Ugui Menu Controller** 的对象。
2. 滚到 **回调事件** 区域。
3. 展开 **On Sub Menu Button Clicked**。
4. 点击 **+** 添加一行监听：
   - **Object**：拖入挂有 `DotweenUguiCarPaintMenuBridge` 的物体（或你的自定义脚本物体）。
   - **Function**：选择  
     `DotweenUguiCarPaintMenuBridge` → `HandleSubMenuButtonClicked (string, string, string, string)`  
     四个参数顺序为：`(mainMenuId, mainMenuName, subButtonId, subButtonName)`。
5. 若用方式 B，请 **禁用** 桥接的自动订阅，或 **移除** 桥接组件，避免重复触发（见下方「方式 C」自定义脚本）。

**主菜单事件（可选）：**

同样在 **On Main Menu Selected** 里 **+**：

- 可用于：切换主 Tab 时隐藏 3D 说明、播放音效、刷新标题等。
- 函数签名：`(string menuId, string menuName)`。
- 注意：主菜单选中时 **不会** 切换车漆，只有子按钮才会。

---

#### 方式 C：自定义脚本接收子菜单事件

新建脚本，挂在任意场景物体上：

```csharp
using MinoHMI.DOTweenUGUI;
using UnityEngine;

public class MyMenuListener : MonoBehaviour
{
    [SerializeField] private DotweenUguiMenuController menuController;

    private void OnEnable()
    {
        menuController.MainMenuSelected.AddListener(OnMainSelected);
        menuController.SubMenuButtonClicked.AddListener(OnSubClicked);
    }

    private void OnDisable()
    {
        menuController.MainMenuSelected.RemoveListener(OnMainSelected);
        menuController.SubMenuButtonClicked.RemoveListener(OnSubClicked);
    }

    private void OnMainSelected(string menuId, string menuName)
    {
        Debug.Log($"主菜单: {menuId} / {menuName}");
    }

    private void OnSubClicked(string mainId, string mainName, string subId, string subName)
    {
        Debug.Log($"子按钮: {mainName} -> {subName} ({subId})");
    }
}
```

或在 Inspector 里把 `OnSubClicked` 绑到 **On Sub Menu Button Clicked**（无需写 `OnEnable`，Unity 会序列化持久监听）。

## 四、事件参数说明（挂回调时必看）

### On Main Menu Selected

| 参数 | 类型 | 来源 | 示例 |
|------|------|------|------|
| arg0 | string | `menuId` | `CarPaint` |
| arg1 | string | `menuName` | `车漆` |

**触发时机：** 点击主按钮动画结束后；场景启动选中 `defaultMainMenuIndex` 时也会触发一次。

---

### On Sub Menu Button Clicked

| 参数 | 类型 | 来源 | 示例 |
|------|------|------|------|
| arg0 | string | 当前主菜单 `menuId` | `CarPaint` |
| arg1 | string | 当前主菜单 `menuName` | `车漆` |
| arg2 | string | 被点击子按钮 `buttonId` | `Paint_1` |
| arg3 | string | 被点击子按钮 `buttonName` | `曜石黑` |

**触发时机：** 用户点击某一子按钮，且点击缩放动画播完后。

**车漆桥接如何用这些参数：**

1. 若 `arg0 != carPaintMainMenuId`（且过滤字符串非空）→ 直接 return。  
2. 用 `arg2`（subButtonId）查 `Paint Bindings` 表 → 得到 `presetIndex`。  
3. 调用 `carPaintSwitcher.SwitchToPreset(presetIndex)`。

## 五、完整数据对照表（复制用）

假设车模有 3 个预设，菜单只有「车漆」一项：

| 配置位置 | 字段 | 值 |
|----------|------|-----|
| CarPaintSwitcher | paintPresets[0] | 珍珠白材质 |
| CarPaintSwitcher | paintPresets[1] | 曜石黑材质 |
| CarPaintSwitcher | paintPresets[2] | 金属蓝材质 |
| Menu Data List[0] | menuId | CarPaint |
| Menu Data List[0] | subButtons[0].buttonId | Paint_0 |
| Menu Data List[0] | subButtons[1].buttonId | Paint_1 |
| Menu Data List[0] | subButtons[2].buttonId | Paint_2 |
| CarPaintMenuBridge | carPaintMainMenuId | CarPaint |
| Paint Bindings[0] | subButtonId / presetIndex | Paint_0 / 0 |
| Paint Bindings[1] | subButtonId / presetIndex | Paint_1 / 1 |
| Paint Bindings[2] | subButtonId / presetIndex | Paint_2 / 2 |

**三处 `Paint_0` 字符串必须完全一致**（区分大小写）。

## 六、Play 模式自检清单

1. **进入 Play** 后 Hierarchy 是否出现 `MainButton_*`、`SubButton_*`？  
   - 没有 → 检查 `Menu Data List` 是否为空、`Menu Controller` 是否启用。
2. 点击主菜单「车漆」，子按钮是否带滑入动画出现？  
   - 没有 → 看 Console 是否有 DOTween 报错。
3. 点击「珍珠白」，Console 是否无 `未找到子按钮映射` 警告？  
   - 有 → `buttonId` 与 `Paint Bindings.subButtonId` 不一致。
4. 车模颜色是否在约 `transitionDuration`（默认 1.2s）内过渡？  
   - 无变化 → `Car Paint Switcher` 未赋值或预设 `sourceMaterial` 为空。
5. 若颜色切了两次 → 同时用了方式 A 自动订阅 + 方式 B Inspector 重复绑定，去掉其一。

## 七、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| Play 后主菜单/子菜单按钮完全没生成 | 菜单预制体在 Project 窗口而非场景中，或在预制体编辑模式打开 | 确保 `DotweenUguiMenuTemplate` 拖入**场景 Canvas 子物体**，并在场景视图中 Play |
| `Cannot instantiate objects with a parent which is persistent` | Inspector 中的引用字段指向了预制体资源而非场景实例 | 脚本已自动修正，查看 Console 警告信息。如仍出现请清空引用让脚本自动查找 |
| 子按钮点了没反应 | 桥接未启用或未赋值 Menu Controller | 检查组件勾选与引用 |
| 警告「未找到子按钮映射」 | buttonId 与 Bindings 不一致 | 对照第五节表格 |
| 警告「预设索引超出范围」 | Bindings 的 index ≥ PresetCount | 减少子按钮或增加 paintPresets |
| 主菜单有反应，车漆不动 | carPaintMainMenuId 与 menuId 不一致 | 统一为 `CarPaint` 或留空过滤 |
| 切换了两次 | 自动订阅 + Inspector 各绑一次 | 只保留一种方式 |
| 想改按钮样式 | 需自定义 Template | 在预制体中指定 `Main Menu Button Template`，替换 Image / 字体 |

## 十、扩展：子按钮触发非车漆逻辑

在 **On Sub Menu Button Clicked** 再 **+** 一条监听（可与桥接并存，注意不要重复调车漆）：

- 例：`subId == "Paint_0"` 时播放粒子、`subId.StartsWith("Seat_")` 时换内饰材质等。
- 或在 `OnSubClicked` 里 `switch (subId) { ... }`。

主菜单切换业务放在 **On Main Menu Selected**，不要与子菜单混用同一个函数。
