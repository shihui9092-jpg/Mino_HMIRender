# MaterialControl 材质变体目录 — 使用说明

## 功能概述

**材质变体目录**（`MaterialVariantCatalog`）用于按「材质种类」管理多组材质球，并支持：

- 每组配置 **本体材质球** + 多套 **变体材质球**
- 一键将变体参数赋予所有种类的本体（全局变体按钮）
- 按变体配置 **平滑过渡时间**，逐类、逐套独立控制
- **Shader 校验**：不同种类可用不同 Shader，同一种类内须一致

组件菜单：**MinoHMI → 材质控制 → 材质变体目录**

---

## 快速接入

1. 在场景中选中需要管理的物体（或新建空物体）。
2. **Add Component** → `MinoHMI/材质控制/材质变体目录`。
3. 在 Inspector 中点击 **本体材质球凹槽** 右侧 **+**，添加第一个材质种类组。
4. 为每组配置：
   - **本体材质球**
   - **材质球命名**（组标题，可留空自动用本体名）
   - **变体槽位列表**（展开后添加 Element 1、Element 2…）
5. 配置完成后，使用下方 **全局变体参数应用** 按钮预览切换效果。

## 字段说明

### 材质种类组（每点击 + 增加一组）

| 字段 | 说明 |
|------|------|
| **本体材质球** | 场景中实际使用的目标材质，变体参数最终应用到该材质上 |
| **材质球命名** | 种类组在 Inspector 中的显示标题；留空时自动使用本体材质球资源名 |
| **变体槽位列表** | 该种类下的多套变体配置 |

### 变体槽位（Element N）

| 字段 | 说明 |
|------|------|
| **变体材质球** | 已调好的参考材质，作为参数来源 |
| **平滑过渡时间（秒）** | 应用该变体时，本体材质参数插值到目标值的时长；**0** 表示立即切换 |

## 全局变体参数应用

- 按钮数量 = 所有种类组中 **已配置变体** 的最大序号（按 Element 1、2、3… 对应变体索引 0、1、2…）。
- 点击 **「赋予全部本体：变体 N」** 后：
  - 每个种类组读取 **第 N 个变体槽位** 的材质与过渡时间
  - 将该变体参数赋予 **该组本体材质球**
  - 过渡时间 &gt; 0 时平滑插值（Float / Color / Vector）；贴图、Int、Keywords 在过渡结束时切换
- 无该变体槽位的种类组会自动 **跳过**。
- 编辑器下支持 **Ctrl+Z** 撤销；编辑模式与运行模式均可过渡（编辑器通过 `EditorApplication.update` 驱动）。

### 按钮禁用时的排查

按钮变灰时，下方会显示 **禁用原因**，常见情况：

| 原因 | 处理建议 |
|------|----------|
| 组内 Shader 不一致 | 检查该组本体与所有变体是否同一 Shader |
| 未配置本体 / 变体 | 拖入对应材质球 |
| 变体 N 在所有组中均未配置 | 至少一组配置该序号的变体槽位 |
| 本体与变体 N 的 Shader 不一致 | 换成与本体相同 Shader 的变体材质 |

## Shader 规则

| 范围 | 规则 |
|------|------|
| **不同种类组之间** | 允许使用 **不同 Shader**（如地面、天空、车身各不相同） |
| **同一种类组内部** | **本体 + 所有变体** 必须使用 **相同 Shader** |

组内不一致时，Inspector 顶部会出现黄色警告，并标明具体种类组与材质名。该组不会参与全局按钮的应用（其他组不受影响）。

## 推荐工作流

1. **按材质类型建组**：地面、山体、天空、车身等各建一个种类组，各拖入对应本体材质。
2. **为每组添加变体**：在变体槽位列表中增加 Element 1、2、3…，分别对应晴/雨/雪等已调好的材质球。
3. **设置过渡时间**：例如晴天 0.5s、雨天 1.2s；需要瞬间切换的变体设为 **0**。
4. **统一 Shader（组内）**：确保同组内所有材质球使用同一 Shader 资源。
5. **预览**：点击全局变体按钮，在 Scene/Game 视图中查看平滑切换效果。
6. **运行时使用**：其他脚本可调用公开 API（见下文）驱动切换。

## 代码调用示例

```csharp
MaterialVariantCatalog catalog = GetComponent<MaterialVariantCatalog>();

// 应用全局变体索引 0（对应 Element 1 / 变体 1），启用平滑过渡
catalog.TryApplyVariantToAllCategories(0, useSmoothTransition: true, out string message);

// 仅对指定种类组应用变体索引 1（对应 Element 2 / 变体 2）
catalog.TryApplyVariantPropertiesToBody(entryIndex: 0, variantIndex: 1, out string error);

// 校验各组内部 Shader
catalog.ValidateCatalogShaderConsistency(out string shaderError);

// 查询全局变体按钮数量
int buttonCount = catalog.GetGlobalVariantSlotCount();
```

## 注意事项

1. **材质引用**：请拖入 **场景实例** 或 **Project 中的材质资源**；本体材质应为运行时实际渲染使用的材质。
2. **数组序号**：界面 Element 1 = 代码 `variantIndex` 0；全局按钮「变体 1」与 Element 1 对应。
3. **过渡中再次点击**：会从 **当前材质状态** 重新向新变体过渡，不会重置到初始状态。
4. **组件禁用**：`OnDisable` 时会清除进行中的过渡；重新启用后需再次点击按钮应用。
5. **序列化升级**：若从旧版 `variantMaterials[]` 升级，需在 Inspector 中重新配置 **变体槽位列表**。

## 常见问题

**Q：点击按钮没有视觉变化？**  
A：确认本体材质是否挂在当前可见物体上；检查 Shader 是否一致；过渡时间是否过长；Console 是否有报错。

**Q：只有部分种类组生效？**  
A：未配置该变体序号的组会被跳过；组内 Shader 不一致的组不会应用。查看操作结果 HelpBox 中的统计与失败信息。

**Q：编辑模式下能否预览？**  
A：可以。在 Editor 中点击全局按钮即可平滑过渡，并支持撤销。

**Q：能否只过渡颜色不过渡贴图？**  
A：当前实现中，Float/Color/Vector 在过渡过程中插值；贴图在过渡结束（t=1）时切换，避免中途贴图突变。
